# Settlement

Immediate transfers may settle in the same request cycle. Scheduled transfers remain queued until execution.

## Settlement Modes

- Immediate
- Scheduled
- Queued
- Retry
- Manual review

## Tracking

- Settlement reference
- Submitted timestamp
- Sent timestamp
- Settlement timestamp
- Completion timestamp
- Returned timestamp

## Notes

Settlement is a workflow concern. Financial truth still belongs to the Ledger through the Transaction Engine.
